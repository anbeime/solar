# 从0到1：光伏储能垂直目录站的GEO实战复盘

## 前言

2024年，AI搜索开始颠覆传统SEO。当用户从"搜Google"变成"问AI"，一个新的战场悄然开启——**GEO（Generative Engine Optimization，生成式引擎优化）**。

本文是我开发「光伏储能地图目录站」的真实复盘，涵盖从数据采集、架构设计到GEO优化的完整流程。

---

## 一、为什么选择光伏储能赛道？

### 1.1 赛道分析

光伏储能是政策驱动型赛道，数据高度公开：
- **数据源丰富**：国家能源局、北极星光伏网、CNESA储能联盟、招投标平台
- **搜索意图明确**：用户搜索"XX市光伏项目"、"储能电站分布"，意图非常聚焦
- **竞争格局**：现有玩家都是综合平台（如公众环境研究中心），没有垂直精耕者

### 1.2 GEO价值判断

| 判断标准 | 光伏储能赛道 |
|---------|-------------|
| 公开结构化数据？ | ✅ 极其丰富 |
| 搜索意图明确？ | ✅ 高度聚焦 |
| 现有玩家是综合站？ | ✅ 机会窗口 |

## 二、技术架构

### 2.1 技术栈

```
前端：HTML5 + CSS3 + Vanilla JS（无框架依赖）
地图：高德地图JS API（集成充电桩、储能站点）
后端：纯静态 + JSON数据（降低部署复杂度）
爬虫：Python + requests + BeautifulSoup
CI/CD：每日凌晨自动更新数据
```

### 2.2 数据架构

```

├── bidding.json       # 200条招标公告

└── statistics.json    # 汇总统计
```
