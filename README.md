# 光伏储能地图站 - 行业大数据平台

## 📋 项目概述

光伏储能地图站是一个完整的行业数据采集与可视化平台，采集自国家能源局、北极星光伏网、CNESA储能专委会及招投标平台等权威数据源。

## 📁 项目结构

```
光伏储能地图站/
├── index.html              # 主网站入口
├── crawler/                 # 数据采集脚本
│   ├── crawl_nea.py        # 国家能源局爬虫
│   ├── crawl_bjx.py        # 北极星光伏网爬虫
│   ├── crawl_cnesa.py      # CNESA储能数据爬虫
│   ├── crawl_bidding.py    # 招投标数据爬虫 ⭐新增
│   └── merge_data.py       # 数据整合脚本
├── data/                    # 数据存储
│   └── projects.json       # 整合后的项目数据
├── cron_update.sh          # 定时更新脚本
└── README.md
```

## 🚀 快速开始

### 1. 安装依赖
```bash
pip install requests beautifulsoup4 lxml
```

### 2. 运行数据采集
```bash
cd 光伏储能地图站/crawler
python3 merge_data.py
```

### 3. 启动网站
直接用浏览器打开 `index.html`，或使用本地服务器：
```bash
python3 -m http.server 8080
# 访问 http://localhost:8080
```

### 4. 设置定时更新
```bash
# 添加到 crontab
crontab -e
# 添加行: 0 2 * * * /path/to/光伏储能地图站/cron_update.sh
```

## 🔧 爬虫功能

### 1. 国家能源局爬虫 (crawl_nea.py)
- 搜索"建档立卡新能源发电项目"公告
- 采集月度新增光伏项目数据
- 支持省份、项目名、容量、类型提取

### 2. 北极星光伏网爬虫 (crawl_bjx.py)
- 采集重点项目列表
- 解析表格和文本数据
- 支持627个光伏项目(58.7GW)数据

### 3. CNESA储能爬虫 (crawl_cnesa.py)
- 采集储能装机统计数据
- 各省储能排名
- 储能项目详情

### 4. 招投标爬虫 (crawl_bidding.py) ⭐
- **支持多个数据源**：
  - 中国招标投标公共服务平台 (ctbpsp.com)
  - 能源招采网
  - 各省公共资源交易平台
- 采集招标公告、中标信息
- 自动提取金额、省份、截止日期
